Trabajo práctico desarrollado para la materia Computación 3 de la Universidad Nacional de Lanús (UNLa). El proyecto consiste en el rediseño integral y maquetado de un sitio web dedicado a difundir la oferta cultural, histórica y gastronómica del barrio de Recoleta, Ciudad Autónoma de Buenos Aires. A partir del relevamiento y análisis crítico de la página original, se planteó una identidad visual completamente nueva junto con una arquitectura de información y estructura HTML renovadas desde cero.

- **Editor de código:** Visual Studio Code.
- **Resolución base:** Diseñado para pantallas de escritorio de 1920 x 1080px, con adaptabilidad para dispositivos móviles.
- **Tecnologías:** HTML para la estructura, JavaScript para interactividad y CSS mediante una hoja de estilos centralizada para trabajar la estetica del proyecto.

## Estructura del proyecto:
- **index.html:** Página principal con presentación del barrio y mapa interactivo.
- **agenda.html:** Calendario de actividades y eventos.
- **ccr.html:** Sección dedicada al Centro Cultural Recoleta.
- **cementerio.html:** Recorrido histórico por el Cementerio de la Recoleta.
- **gastronomia.html:** Guía de restaurantes y circuitos gastronómicos.
